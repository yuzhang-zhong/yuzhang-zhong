# Profile icon sources

- `tracefork.svg`: the project's existing icon, copied unchanged from [TraceFork](https://github.com/yuzhang-zhong/TraceFork/blob/main/public/tracefork-icon.svg).
- `rewind.svg` and `learning.svg`: custom project marks designed for this profile: paired rewind ribbons and a storybook with an imagination spark.
- `cat.svg`: the original sitting Pixel Banban artwork from the [public sprite gallery](https://github.com/yuzhang-zhong/banban-desktop-releases/blob/main/media/sprite-gallery.png). A cropped SVG viewport displays only that pose; the embedded source PNG bytes are unchanged.
- `homepage.svg` and `email.svg`: generic website and email symbols created for this profile.
- `linkedin.svg`: [Font Awesome's LinkedIn brand icon](https://api.github.com/repos/FortAwesome/Font-Awesome/contents/svgs/brands/linkedin.svg), Fonticons, Inc., licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Adapted with LinkedIn blue, a white background, and an accessible title. The original copyright and license comment is retained.
- The RedNote icon is reused from the [public homepage's existing asset](https://github.com/yuzhang-zhong/yuzhang-zhong.github.io/blob/main/images/rednote-icon.png).
